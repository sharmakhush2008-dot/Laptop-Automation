# Laptop Automation

A Python project I'm building to learn programming by creating simple laptop automation tools.

## Current Goal

Start with basic filesystem automation and gradually build more capable tools as I improve my Python and programming skills.

## Current Features

- List the contents of a folder

## Learning

This project is also a way for me to understand:

- Python
- Functions
- Variables
- Modules
- File and folder operations
- Error handling
- Git and GitHub
- Software development practices

## Roadmap

### Level 1 — Filesystem Basics
- [x] List folder contents
- [x] Check if a file/folder exists
- [x] Create folders
- [x] Find files

### Level 2 — File Management
- [ ] Rename files
- [ ] Move files
- [ ] Copy files
- [ ] Delete files

### Level 3 — Automation
- [ ] Automate repetitive file tasks
- [ ] Organize files automatically
- [ ] Add more useful commands

### Level 4 — Command Interface
- [ ] Create a simple command system
- [ ] Add input handling
- [ ] Add error handling

### Level 5 — Natural Language
- [ ] Experiment with natural-language commands
- [ ] Connect commands to predefined safe actions

## Project Philosophy

The goal isn't to have AI write the whole project for me.

I want to use AI as a teacher, debugger, and thinking partner while gradually learning to write the code myself.

**AI explains → I understand → I modify → I write → I build.**
